# Pytania przed pracą

Model nie zgaduje - najpierw dopytuje o to, co zmienia wynik.

## Prompt

```text
Zanim zaczniesz, zadaj mi maksymalnie 5 pytań, których odpowiedzi zmienią wynik: zakres, odbiorca, format, ograniczenia, kryterium sukcesu. Wszystkie w jednej wiadomości, z opcjami do wyboru. Potem czekaj na odpowiedzi.
```

## Kiedy używać

Każde zadanie opisane jednym zdaniem: tekst, kod, analiza, grafika.

## Jak

Wklej prompt na początku rozmowy z dowolnym modelem (Claude, ChatGPT, Gemini) albo do instrukcji systemowej agenta, a potem opisz zadanie.

## Źródło

Inspiracja: Reverse prompting / clarify-first protocol (github.com/DmiyDing/clarify-first). Sformułowanie po polsku: OTW.
